LxthalFC Pack System

Twelve stages from a blank slate to a shoot-ready pack, every one naming the exact call to make. Built from one seventeen-pack batch and the twenty-four errors it produced.

1 · Decide by defaultEscalate only a genuine fork — options genuinely close, and the choice taste rather than evidence. Everything else you decide, state the reasoning, and name the cost so it can be overruled in one tap. Flagging feels safe and is not: it moves the work to him.

02

Reference audit

Eight checks, every one cheap, every one having caught a real failure.

start_video_analysis(url, media_resolution="default", prompt=<audit>) — 4+ in parallel
get_video_analysis_result(job_id)
  1. Rank-label overlap. Is the pick's wording in the reference's own captions? Then it was transcribed, not chosen. A reference is a format source, never a content source.
  2. Structure. Ranked countdown / single story / bracket / head-to-head / compilation. A pack inherits it or declares it is departing.
  3. Genre gate. Gameplay sim is an automatic reject. This one check would have caught three failures in a single batch.
  4. Title-promise match. Does it ask the same question? And any link appearing against more than one queued idea is unverified for all of them — one sat against seven.
  5. Lane proof is not format proof. A big video in the right lane proves the lane, not the title.
  6. Visible-game-UI standard. See Stage 4.
  7. Parent-number check. List the parent's entries by name and moment. Same player different moment is fine; same moment is a re-cut.
  8. Title promise on each pick, no placeholders. A striker under a goalkeeper title fails. A boot of noodles under a lookalikes title fails.

Output one refaudit/<pack>.md per pack: what the reference actually contains, and the verdict.

03

Source the clip

Never declare a moment unfindable after one search.

youtube_search(query, type="video", sort_by="view_count") — several angles at once
  1. Player + opponent + competition + action
  2. How a fan would phrase it — surfaces the viral cut; formal phrasing surfaces the archive
  3. Official match highlights for that fixture
  4. The reference it came from — three picks were written as "no clip found" while the frames sat in a Short already in hand
  5. Category compilations — highest-value target. One official compilation verified five picks in a single pass
  6. Native-language phrasing for non-English leagues

Keep queries to three or four words. Long descriptive queries return zero. Prefer official league/club/federation → broadcaster → large clip channel → meme edit.

Gate 3Only declare unsourceable after two distinct angles and a compilation search and a re-watch of the reference. If a search returns only gameplay, the moment probably is not real.
04

The watch

One scoped pass per moment, not one per video.

start_video_analysis(url, media_resolution="default", prompt=<scoped>) — all in parallel
Cost — check the source duration, not the windowA pass bills on the whole video. A 16-minute compilation is ~15 credits per moment, so five moments in one compilation is ~75, not ~15. Quote the real number before spending. E15

The standing prompt asks for, by name

  1. All on-screen caption text exactly, character for character — he plants misspellings as comment bait
  2. Shirt numbers only where literally readable, with "not legible" required otherwise
  3. The ranking number shown on screen
  4. How each clip ends — and which corner
  5. Anywhere on-screen text contradicts the narration
  6. Commentary verbatim with timestamps — the highest-value output of any watch. It names players, settles outcomes, and hands over captions free
  7. Real vs game vs fabricated, per segment
  8. An explicit CANNOT DETERMINE section. Ask for it by name. A gap beats a confident error

Three modes — match the mode to the moment

  • Numbered beats with timestamps where the sequence is the story — scrambles, deflections, goal-line pinball
  • Named stations, no clock where the event is under two seconds — receiving, the feint, the turn, the exit
  • Hybrid where there is both a technique and a sequence — dives, long runs, two-part events

One vocabulary, fixed

SOURCEAUTHENTICPICTURESCENE READ OFF THE KITBOARDSCROWDSCOREBUG BROADCAST GRAPHICSOVERLAYSPEED GRAPHIC DELIVERY / ACTIONCELEBRATIONCAMERA COMMENTARYAUDIOCANNOT DETERMINE

BOARDS is pitchside sponsors, CROWD is fan banners, BROADCAST GRAPHICS is the broadcaster's overlays and OVERLAY is the publisher's — the ones the editor must mask. The two keyed fields appear as labels in every file, never buried in prose.

Safe / soft / unsafe

  • Safe — which foot, how it ends, on-screen text, commentary, kit, camera angles, whether play stopped
  • Soft — touch counts, steps, distances, timings. Say the foot, never the number. Son returned 9, then 10, then 11–12 across three passes; the feet never once disagreed
  • Unsafe — player identity and outcome. Run the ending check, then take conflicts to Stage 5

Is it a game? Unreliable in both directions

Official club, league and federation channels are trusted by default — a gameplay flag on one is the model being wrong. A call only counts with visible game UI: squad menus, rating cards, stamina bars, radar, controller prompts. Roster plausibility is worthless. A true positive looks like a PS5 logo under the scoreline.

Fabricated means game or doctored — catch it with a scoreboard that contradicts itself between two shots of the same passage. Manipulated means real footage padded by looping, scrubbing or speed change. Check whether a "long" moment is actually long.

Depth must be even

Measure it. One pack averaged 382 words a clip while another averaged 713 — and the thin one was the two-part goalkeeper pack that least deserved to be thin. If one clip is a third the length of its pack-mates, that is a gap, not a style.

Gate 4Every pick has its own clip watched in this run. Never write a beat from a previous note — E05. A comment can nominate a pick; only footage can confirm one.

Verify independently

The stage that catches the worst errors. Do not hand him a question you could answer with a search.

WebSearch → WebFetch the best source — the club's own site over an aggregator

Everything in this list goes to the record before it is written down:

  • The type of restart — goal kick, free kick, open play, corner (E04)
  • Any outcome — scored, saved, wide, over, which post (E08)
  • Any number that will be spoken or appear on screen (E06)
  • Dates, competitions, fixtures, scorelines
  • Any award, record or ruling
Gate 5Every such claim carries a named source in the pack sheet. If a number is not in the footage, say so explicitly, so he knows he is adding it.
06

Tie-break

When two passes disagree, a third scoped to the single clearest angle.

Ask only the disputed question, and require four things: the answer; the visual evidence for it, naming which leg plants and which boot contacts; a grade of certain / likely / unsure; and whether the moment of contact is actually visible or obscured. Tell it plainly that an honest "cannot tell" is more useful than a confident guess.

This settled Čech's kicking foot as left against an earlier pass that said right, and settled Son's feet while honestly reporting that the clearest angle starts mid-run.

07

Assemble

The formula, and the checks that stop a pack repeating itself.

5→1. #5 proven hook · #4 most engaging or controversial · #3 engaging · #2 least engaging but proven · #1 conventional finisher, hard declarative. If Part 1 ran 5→1 under a "Top 10" title, Part 2 runs 10→6.

Variety is judged on the footage, not the label. Duplicates are defined by mechanism, not outcome — three penalties all ending over the bar can still be fine if one's cause is unique. When two picks share a mechanism, name the pair and drop one.

Counting across a pack finds lines nobody else has. "Every one of these runs is one-footed" came out of tallying feet across five clips. "Every delivery method that appears twice splits by side" came out of re-counting a taxonomy.

08

Decide

Law 1 lives here.

For each open question, ask two things. Are the options genuinely close? If one is clearly better on evidence, decide it. Is the choice taste or evidence? Evidence is yours. Taste is his.

When you decide: state the reasoning, name the cost plainly, and put the alternative in the subs so it reverses in one tap.

When it is a genuine fork, it goes in the notes app's decisions panel — never only in chat, never only in a PDF, and never in a calendar. Two to four concrete, tappable options, never an open-ended question. Include the do-nothing option where one exists. Mark your recommendation once and leave it.

AlwaysSurface the app link in your reply every time something needs his input.
09

Deliver

The app, the PDF, and three checks in this order.

Status labels describe the pack's readiness, never the audit's verdict: Locked · Needs a call · Shoot knowing (complete, no format precedent) · Slots open.

  1. Parse — eval the arrays with node before republishing. One broken quote blanks the page.
  2. Render and read it back — pdftoppm a page to an image and open it. A parse check is not a render check (E11).
  3. Click through — Playwright with the preinstalled Chromium, window.claude stubbed to an in-memory db. Screenshot at 390px and in dark mode.
Bound every in-place spliceCompute the array's start and end first, pass both to every find(), and recompute the end after each edit. An unbounded find jumped into the next array and produced an eighteenth pack. E12

PDFs: reportlab + DejaVu. Strip emoji, CJK and Arabic — they render as empty boxes. pypdf.extract_text throws on subsetted DejaVu; ignore it and use pdftotext.

9.5

QA gate

Runs before delivery, and it blocks. 592 checks, every one descended from a real error.

python3 qa.py — everything · exit non-zero blocks delivery
python3 qa.py --pack <id> — one pack
python3 qa.py --json — machine-readable

Three severities. FAIL blocks — nothing ships until it is fixed. WARN does not block, but every warning must be acknowledged by name in the report; silently passing one is the same as hiding it. INFO is a note, usually a soft figure that should stay out of the script.

The adversarial pass — because self-grading is weak

The script catches what is mechanical. It cannot catch a wrong claim that is well-formed. So once the gate returns clean, spawn a subagent whose only job is to find faults:

Find what is wrong, not what is right. Does any description contradict itself? Is any outcome, date, competition, award or type of restart stated from footage rather than the written record? Is any number presented as fact the footage cannot support? Do two picks share a mechanism? Does any pick fail the title promise? Report only problems, with file and line, ranked by damage.

A reviewer that reports nothing has not done its job — send it back once with the weakest pick named. Anything it confirms goes into the log.

The rule this stage exists to enforceA parse check is not a render check, and neither is a truth check. The three layers are mechanical, visual and adversarial. Running one and calling it QA is how E11 and E16 both shipped.
10

Self-audit

Never skip. This is the part that makes the system improve.

  • Paste the QA gate’s own summary line — passed / warnings / failures — then list every warning by name and say what you did about each. Report only the failures.
  • List what you got wrong, including anything corrected mid-run. What, why, and the rule that would have prevented it.
  • Append each to the error log with a new E-number. If the error was mechanically detectable and the gate missed it, add a check for it to qa.py in the same breath — that is how the gate gets stronger instead of staying still.
  • Check for a new pattern. The log names five. Say which this run's errors fit, or add a sixth.
  • Propose the skill update so the lessons survive a lost log.
  • Report in plain prose — what shipped, what you decided and why, what is genuinely waiting on him, and what you got wrong. Own errors out loud and say which part changed. Never quietly reissue.
